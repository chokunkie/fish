# SALA HUM — Community Aquaculture Demo

ต้นแบบเว็บจำลองการติดตามกระชังปลากะพงบ้านศาลาหุม สไตล์ห้องควบคุมโรงงาน ใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจ

เว็บที่ deploy: https://sala-hum-control.dewyhen73.chatgpt.site

## ผู้เลี้ยงและ LINE OA จำลอง

- หน้าหลักแสดงกระชัง 6 อัน พร้อมสถานะสีและคำแนะนำสั้น กดดูรายกระชังได้
- ผูกบัญชีครั้งเดียวด้วยรหัส `C-01` ถึง `C-06` แล้วจำรหัสกระชังไว้ในเบราว์เซอร์
- ทดลองเบอร์โทรเดโม `0800000000` และ OTP `123456` ได้ โดยไม่มีการส่ง SMS หรือเก็บเบอร์โทร
- LINE Rich Menu กดสถานะ คำเตือน วิธีรับมือ ติดต่อผู้ดูแล ประวัติ และบัญชีได้
- คำขอความช่วยเหลือและรับทราบจะเพิ่มเหตุการณ์ในรอบเดโม ไม่มีการส่งออก LINE จริง

## Admin ระดับองค์กร

ใช้รหัส `demo-admin` เพื่อทดลอง UI เท่านั้น รหัสนี้เปิดเผยโดยตั้งใจ ไม่มีการยืนยันตัวตนฝั่งเซิร์ฟเวอร์หรือสิทธิ์เข้าถึงข้อมูลจริง

- ผัง GIS จำลอง 6 จุด เลือกกระชังและย่อขยายได้ ตำแหน่งและเส้นชายฝั่งเป็นตัวอย่าง ไม่ใช่พิกัดสำรวจ
- ดูค่า DO ความเค็ม pH และอุณหภูมิ พร้อมกราฟและเกณฑ์เตือนที่ปรับได้
- เลือกแนวโน้มมรสุม/น้ำหลาก 6, 12 หรือ 24 ชั่วโมงจากสถานการณ์สมมติ ไม่ใช่การพยากรณ์อากาศจริง
- บันทึกแผนเตรียมเครื่องเติมอากาศส่วนกลาง ประสานหน่วยงานด้านน้ำ หรือตรวจน้ำร่วมกันได้ ไม่มีการสั่งอุปกรณ์หรือส่งคำขอจริง
- ประวัติน้ำ เหตุการณ์ และ CSV เป็นข้อมูลในรอบจำลองปัจจุบัน

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หากใช้ชุดที่มีโฟลเดอร์ dist ให้เปิด `dist/index.html` หรือให้ static HTTP server ให้บริการโฟลเดอร์นั้น เช่น:

```sh
python -m http.server 8080
```

สำหรับชุดที่มี dist ใช้ `python -m http.server 8080 --directory dist` แล้วเปิด http://localhost:8080

ฟอนต์ Google Fonts ใช้อินเทอร์เน็ต ถ้าออฟไลน์จะใช้ฟอนต์สำรองบนเครื่อง ไม่มี API keys, backend, ฐานข้อมูล หรือบริการเก็บข้อมูลผู้ใช้

## ตรวจสอบแบบจำลอง

```sh
node --check app.js
node tests/simulation.cjs app.js
```

ในชุด source ที่มี dist ให้แทน app.js ด้วย dist/app.js การตรวจครอบคลุมสถานการณ์น้ำ การเติมอากาศ เซ็นเซอร์ขัดข้อง เกณฑ์เตือน บัญชีเดโม และการป้องกันข้อความ HTML ในแผนรับมือ

## ขอบเขตข้อมูล

อ้างอิงแนวคิดที่ผู้ใช้ให้ใน กระพงขาว.docx วันที่ 23 ตุลาคม 2569 ข้อมูลน้ำ กระชัง ปริมาณปลา เกณฑ์เตือน และผลการควบคุมทั้งหมดเป็นการจำลอง ไม่มี AI ที่ฝึกหรือยืนยันความแม่นยำแล้ว ไม่ใช้ความเค็มต่ำกว่า 28 ppt เป็นกฎว่าปลากะพงต้องตาย และไม่รับรองผลเพิ่มอัตรารอดหรือรายได้

ภาพพรีวิวกล้องเป็นภาพนิ่งจาก Data Pack บ้านศาลาหุม หน้า 7 ที่ผู้ใช้ให้ ไม่ใช่ CCTV สด ที่มา: https://drive.google.com/file/d/10oid8fTfZT1MjBKDswBC7BbLakfzbiJe/view

ก่อนใช้งานจริงต้องมี LINE Login/LIFF และระบบยืนยันผู้ใช้จริง บัญชี Admin ฝั่งเซิร์ฟเวอร์ การกำหนดสิทธิ์ การเชื่อมเกตเวย์ การสอบเทียบเซ็นเซอร์ พิกัดกระชังจริง ข้อมูลฝน/น้ำ และแผนตอบสนองที่ผ่านการทบทวนกับผู้เลี้ยงและผู้เชี่ยวชาญ
